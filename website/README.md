# AnyLearning Website

This repository contains the source code for the AnyLearning website.

## About AnyLearning

AnyLearning is a platform that provides simple, smart, and secure AI model building tools. It allows users to create custom AI models in minutes using no-code tools.

## Features

- Image annotation with AI-powered tools
- Model training for various computer vision problems
- Seamless integration between annotation and training
- Support for different types of computer vision tasks

## Getting Started

To run this website locally:

1. Clone the repository
2. Install dependencies with `pnpm install`
3. Run the development server with `pnpm run dev`
4. Open [http://localhost:3000](http://localhost:3000) in your browser
