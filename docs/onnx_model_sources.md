# ONNX model source matrix

Last reviewed: 2026-08-30

Every new AnyLearning inference adapter consumes ONNX only. Native frameworks
listed below are exporter/reference dependencies used outside the inference
process; they are not runtime dependencies of `anylearning.inference`.

## Reuse rules

1. Record immutable source, exporter, checkpoint, tokenizer/config, and dataset
   revisions in the artifact manifest.
2. Run conversion in an isolated optional training/export environment. Never
   deserialize a downloaded native checkpoint in desktop or server inference.
3. Validate the exported graph, tensor names, dtypes, ranks, static limits, opset,
   external data, SHA-256, native/ONNX parity, and ONNX Runtime provider matrix.
4. Store large cleared artifacts in `nrl-ai` using Git LFS/Xet only after a
   separate weight-license review. The Python package contains manifests and
   checksums, not multi-gigabyte weights.
5. For ONNX models that exceed the single-protobuf limit, publish a manifest
   containing the graph and every external tensor shard with relative paths,
   sizes, and SHA-256 values. The shared loader requires exact manifest coverage,
   bounds referenced byte ranges, and passes verified read-only mappings to ONNX
   Runtime without copying the full bundle. Never follow model-supplied absolute
   paths, parent traversal, symlinks, or hardlinks.
6. Implement preprocessing and postprocessing from documented contracts and
   measured fixtures. If source code is reused, preserve its license and notice
   and keep a provenance record down to the commit.
7. A model with only a community exporter stays experimental until a maintained
   primary source or our own independently tested export profile exists.
